# ⚔️ Tarea - Capítulo 4: Strings

### 1. Declaración e índices

**a) Declaración:**
Declarar una variable utilizando **comillas dobles (`"`), comillas simples (`'`) o backticks (`` ` ``).

**b) Índices:**
Ejecutar el código desde la terminal y buscar un **índice válido** y un índice que **no exista** dentro del String.

---

### 2. Caracteres de escape

**a) Escapes:**
Crear una oración que incluya:

* Un salto de línea `\n`
* Una tabulación `\t`
* Un escape de caracteres especiales

**b) Backticks:**
Crear una oración que incluya los mismos elementos utilizando **backticks**.

---

### 3. Concatenación

Crear **3 variables** con datos personales y utilizarlas para crear un mensaje mediante concatenación.

También se pueden utilizar **Template Strings**.

---

### 4. `indexOf()` e `includes()`

**a) `indexOf()`:**
Crear una variable que contenga la palabra:

```text
Homero
```

Utilizar `indexOf()` para buscar un **índice válido** y comprobar también qué ocurre cuando el elemento **no existe (`-1`)**.

**b) `includes()`:**
Crear una variable que contenga la palabra:

```text
Simpson
```

Utilizar `includes()` para comprobar si el texto contiene un determinado valor y obtener como resultado `true` o `false`.

---

### 5. `length` y `slice()`

**a) `length`:**
Crear una variable y utilizar `.length` para obtener e imprimir la cantidad de caracteres que contiene.

**b) `slice()`:**
Crear una variable llamada `palabra` y otra llamada `palabraNueva`.

Utilizar el método `slice()` para realizar una **separación parcial** del contenido y guardar el resultado en `palabraNueva`.

---

### 6. `trim()`

Crear una variable que contenga la palabra:

```text
   SCRIPT
```

Utilizar los **tres casos de `trim()`** vistos en clase:

* `trim()`
* `trimStart()`
* `trimEnd()`

Observar qué espacios elimina cada método.
