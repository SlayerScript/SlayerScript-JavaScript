# Tarea: Operadores en JavaScript

## 1. Operadores de asignación

Realizar un ejemplo práctico utilizando cada uno de los operadores de asignación (`=`, `+=`, `-=`, `*=`, `/=`, `%=`, `**=`).

## 2. Incremento y decremento

Explicar el resultado de los siguientes fragmentos de código:

```javascript
let contador1 = 100;
console.log(contador1++);

let contador2 = 100;
console.log(--contador2);
```

## 3. Operadores de comparación e igualdad

Explicar el resultado de las siguientes expresiones:

```javascript
console.log("1: " + (85 === "85"));
console.log("2: " + (true != true));
console.log("3: " + (66 >= 66));
console.log("4: " + (42 < 42));
```

## 4. Operadores lógicos

Crear ejemplos utilizando dos variables para demostrar las cuatro combinaciones posibles (V/V, V/F, F/V y F/F) con los operadores lógicos `&&` (AND) y `||` (OR). Además, realizar dos ejemplos utilizando el operador `!` (NOT).
