# Tarea: Condicionales en JavaScrpt

## 1. If, Else If y Else

Crear tres variables utilizando diferentes tipos de datos. Podés utilizar string, number y/o boolean.

Luego, crear una estructura condicional que cumpla con los siguientes requisitos:

El if debe utilizar operadores lógicos (&& o ||).
El else if debe utilizar una única condición, sin operadores lógicos.
El else debe ejecutarse cuando ninguna de las condiciones anteriores se cumpla.
Cada bloque debe mostrar un mensaje diferente mediante console.log().

Objetivo: practicar la evaluación de múltiples condiciones y comprender cómo funcionan if, else if y else.

## 2. Switch

Crear un reloj utilizando switch que represente las horas de un día.

El programa debe tener una actividad especial cada 4 horas.

Por ejemplo:

00:00 → Dormir
04:00 → Levantarse
08:00 → Estudiar
12:00 → Almorzar
16:00 → Entrenar
20:00 → Jugar

Para las horas que no tengan una actividad especial, utilizar default para mostrar un mensaje indicando que no hay ninguna actividad programada.

Objetivo: practicar el uso de switch, case y default.

## 3. Operadores ternarios

Convertir este condicional IF a una operación ternaria

```javascript
let banda = "Judas Priest"
if (banda == "Judas Priest") {
    console.log("PAINKILEEEER");
} else {
    console.log("Painkillern't");
}
```

Objetivo: comprender cómo utilizar el operador ternario para representar condiciones simples de manera más compacta.
